# ClockOut 路线图

以下项目仅为后续规划，不属于 1.0 首版。

## 1.1

- 月历视图
- 周报和月报
- 平均上下班时间
- 累计工作时长
- 午休趋势
- 超出预计工作时间趋势
- 打卡完整率

## 1.2

- Android 桌面小组件
- 通知栏常驻状态
- 通知栏快捷打卡
- 快捷设置磁贴
- 桌面长按快捷操作
- 预置多套可切换 Launcher 图标
- 相册选图与本地裁剪后创建自定义桌面快捷方式（不替换 App Drawer 原始图标）

## 1.3

- 按星期设置不同工作时长
- 半天班
- 夜班和跨日班次优化
- 多段午休
- 节假日和调休设置
- 更智能的本地提醒

## 2.0 可选能力

- Wear OS 快捷打卡
- NFC 标签快捷打卡
- 在用户明确授权后识别第三方考勤通知

## 明确不纳入路线图

这些能力与当前隐私原则冲突：登录和账户、云同步、团队及企业功能、服务端数据库、第三方统计 SDK、自动上传数据、默认写入公共存储、未经明确授权读取其他 App 或日历数据。
