# ClockOut 隐私说明

ClockOut 1.0 是仅供个人使用的离线应用。

- 不提供登录、注册或账户。
- 不连接服务器，不声明联网权限，不使用云数据库。
- 不包含广告、统计、埋点、崩溃上报或第三方跟踪 SDK。
- 打卡记录存放在 Room 数据库，偏好设置存放在 DataStore；全部位于 Android 应用私有目录。
- 不读取或写入公共存储，不导出 CSV/Excel，不进行云同步或外部备份。
- Android 云备份和设备迁移备份已在 Manifest 与数据提取规则中关闭。
- 不申请通讯录、位置、相册、日历、通知读取或无障碍权限。
- 唯一的运行时权限是 Android 13+ 的通知发送权限，且只在用户开启本地下班提醒时申请。拒绝权限不影响其他功能。
- 卸载应用会删除其私有数据。设置页的“删除全部数据”会清空记录和设置，并取消本地提醒。

应用使用 WorkManager 在设备上安排本地提醒。提醒数据不会离开设备。
